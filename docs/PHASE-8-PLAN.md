| Поле | Значение |
|---|---|
| Этап | 8 |
| Состояние | **не начат** — начнётся после этапа 7 |
| Слияние | — |
| Версия | `1.0.0` после пилота (`VERSIONING.md`) |
| Отложенное | см. `BACKLOG.md` |

Основание: `ROADMAP.md` §Этап 8, `VISION.md` (критерии успеха).

## Что должно войти

| Блок | Состав |
|---|---|
| Участники | 2–5 живых людей: преподаватель, ученик (с законным представителем), администратор |
| Ввод | реальное расписание на период, реальные задания и оценки |
| Наблюдение | сбор замечаний по форме «что делал — что ожидал — что получилось» |
| Разбор | правки делятся на «до общей работы» и «в бэклог»; повторная проверка исправленного |
| Решение | вывод «в прод» или список блокеров |

## Критерии приёмки

1. Участники отработали основной сценарий: урок → оценки → домашнее задание → сдача → проверка.
2. Ни одной потери данных и ни одного `500` в ходе пилота.
3. Замечания разобраны, блокеры закрыты.
