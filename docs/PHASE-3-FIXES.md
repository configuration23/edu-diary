### Согласовано в обсуждении (работы по этому списку идут)

Решения владельца после третьего просмотра. Настройки оформления меняет **только администратор**
(право `settings:write`); темы оформления (шрифты, размеры, тёмный режим) — отдельный разговор
позже.

- [x] **Значки событий вместо цветной путаницы.** Цвет означает предмет, значки — события. Замена —
      🔄, отмена — ❎ (плюс серый цвет текста), перенос не обозначаем: урок просто переезжает на
      другое время. Значок чуть крупнее шрифта, в углу плитки, чтобы не мешать основной
      информации. Символ выбирается администратором из набора эмодзи и может быть отключён
      настройкой. В контракте — ровно одна **графема** (эмодзи со стилизующим вариантом — это две
      кодовые точки) и только из набора: значение попадает в интерфейс, произвольная строка
      недопустима.
- [x] **Цвет предмета.** Поле в справочнике предметов, автоподбор по кругу оттенков (не случайный:
      соседние цвета не должны совпадать), возможность правки вручную. Использование: заливка
      плитки в сетках, цветной маркер рядом с названием в строках и больших формах. Отключение
      цветов — настройкой администратора.
- [x] **Правка занятия по клику на предмет** в «Сетке (шаблон)»: блок с формами открывается **под
      сеткой**, выбранная строка подсвечивается, кнопка «Убрать» переезжает в этот блок (удаление
      не должно срабатывать случайным кликом по строке). Кнопка «Править» остаётся как явная
      подсказка.
- [x] **Подсветка кликабельного при наведении** — единое правило по всему приложению: строки и
      элементы списков получают фон, плитки с цветом предмета — рамку и тень (фон не трогаем, он
      несёт смысл), выбранная строка подсвечивается. Реализуется в общих компонентах, а не по
      экранам.
- [x] **Плитка урока — единый состав.** Сейчас название группы появляется только в режиме «Все
      группы». Делаем всегда: первая строка — **код предмета слева и аудитория справа**, вторая
      строка — **название группы** (обрезается многоточием, полное — в подсказке и панели
      деталей). Код обрезается первым на узких колонках, аудитория не обрезается, при отсутствии
      аудитории — «—». Состав плитки не зависит ни от фильтра групп, ни от периода.

- [ ] **Фильтровать преподавателей по назначению при создании урока.** Владелец заметил: в форме
      нового урока сейчас можно выбрать любой предмет и любого преподавателя независимо друг от
      друга. По смыслу предмет в группе ведёт назначенный преподаватель, поэтому логичнее
      подставлять его по умолчанию, а остальных показывать только как замену на один урок
      (с подписью «не по назначению»). Нужно решить: разрешать ли выбор «чужого» преподавателя
      и как это отражать в отчётах.
