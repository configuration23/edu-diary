# SECURITY-PLAN — дополнительный этап «ИБ» (в работе)

| Поле | Значение |
|---|---|
| Этап | ИБ (вне роадмапа) |
| Состояние | **в работе** — бóльшая часть высоких и средних находок закрыта |
| Слияние | ветка `security/hardening` (сливает владелец) |
| Версия | версию не меняет: усиление и исправления внутри этапа (`PATCH`) |
| Отложенное | `BACKLOG.md`, раздел «ИБ: будущие работы» |

Основание: внешнее тестирование и замечания владельца. Требования — `SECURITY.md`, решения —
`DECISIONS.md` ADR-033.

## Что вошло в этап

| Область | Работы | Состояние |
|---|---|---|
| Вход | ступенчатая блокировка (5 → 10 → 20 → 40 мин), лимит по адресу, атомарные счётчики, одинаковый ответ для существующих и несуществующих логинов | **done** |
| Пароли | обязательная смена временного пароля, ограничение смены раз в 6 часов | **done** |
| Сессии | простой 30 минут + предел по роли (12 ч / 30 дней), «Устройства и входы» с отзывом | **done** |
| Канал | CSP, `X-Frame-Options`, `Permissions-Policy`, COOP/CORP, HSTS, `COOKIE_SECURE`, source maps | **done** |
| Запросы | лимит JSON 256 КБ, таймауты, `Cache-Control: no-store` | **done** |
| Данные | обрезка `/api/health` и `/api/setup/status` | **done** |
| Файлы | имена строит сервер, ранний `413`, лимиты `multipart` | **done** |
| Остальное | проверка `Origin`, удаление и квоты файлов, антивирус, сложность пароля, 2FA, лимит сессий, `__Host-`, сроки хранения IP | **в `BACKLOG.md`** |

## Найденные по ходу дефекты (исправлены)

1. Битый JSON давал `500` — теперь `400 VALIDATION_FAILED` (F-07).
2. Картинка новости больше 256 КБ давала `500`: `multipart` без лимитов наследовал лимит тела, а
   код ошибки не был в карте. Теперь `201` для фото и `413` сверх настройки (проверено на стенде).

## Критерии приёмки этапа

1. Все пункты «высокие» и «средние» из отчёта либо закрыты, либо явно записаны в бэклог с причиной.
2. Каждая правка подтверждена тестом (в том числе дефекты, найденные на стенде).
3. Шлюзы зелёные, CI на ветке проходит.
